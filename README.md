Leonida Trophy Guide — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: the official names, descriptions and grades, a guide in our own words with cited sources for every trophy, a roadmap to the platinum, the one missable trophy flagged, and a checklist that saves in your browser (localStorage) with export and import. No online trophies, no network needed — it runs entirely from its own files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
